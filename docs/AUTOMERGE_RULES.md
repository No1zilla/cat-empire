# 📜 Правило логики кнопки «⚡ Соединить» (AutoMergeButton)

1. **Если у игрока >= 5 💎:** 
   - Списываются 5 💎 ➔ происходит объединение котиков (без рекламы).

2. **Если у игрока < 5 💎:** 
   - Показывается реклама ➔ за просмотр рекламы начисляются **+5 💎** в баланс ➔ происходит объединение котиков.
   - **ВАЖНО:** Начисленные за рекламу +5 💎 остаются у игрока на балансе!
