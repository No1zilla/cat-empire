# 📜 Правило логики кнопки «⚡ Соединить» (AutoMergeButton)

1. **Если у игрока >= 5 💎:** 
   - Списываются 5 💎 ➔ происходит авто-объединение котиков.

2. **Если у игрока < 5 💎:** 
   - Кнопка находится в режиме **«🎬 +5 💎»**.
   - Показывается реклама ➔ за просмотр рекламы **начисляются +5 💎 на баланс игрока** (БЕЗ спонтанного самовольного запуска слияния).
   - Кнопка переходит в активный режим **«⚡ Соединить (5 💎)»**, и игрок сам решает, когда запустить слияние!
