# 📜 Правило логики кнопки «⚡ Соединить» (AutoMergeButton)

1. **Если у игрока >= 5 💎:** 
   - Списываются 5 💎 ➔ происходит авто-объединение котиков.

2. **Если у игрока < 5 💎:** 
   - Показывается реклама ➔ за просмотр рекламы **выполняется авто-объединение котиков** (БЕЗ начисления гемов в баланс).
