# 📌 TASK-028: Престиж и «Кошачья мята»

> **Статус:** ⬜ После кассы и 2× бустера  
> **Приоритет:** P1 удержание — без этого после Кото-Бога игра кончается

---

## Зачем для денег

Первая «победа» (15 ур.) сейчас даёт +50 рубинов и всё. Игрок уходит. Престиж открывает второй круг прогрессии — есть кому продавать паки и крутить рекламу на D7+.

## Механика

1. После Кото-Бога: кнопка ритуала перерождения.
2. Сброс поля и цен покупки. Рубины не сжигаем (игрок купил их).
3. Награда: **Кошачья мята** 🌿 за сброс (формула от max-уровня / числа сбросов — зафиксировать в балансе).
4. Магазин мяты:
   - +% к пассивному доходу навсегда за уровень мяты
   - старт спавна с котика 2–3 ур.
5. Сохранение мяты и бустов в `storageService`.

## Критерии

- [ ] Ритуал доступен только с Кото-Богом (или эквивалентным порогом)
- [ ] Сброс поля, мята начислена, доход вырос
- [ ] Повторный престиж работает
- [ ] Сейв переживает рестарт
- [ ] Сборка на `/dev/`
