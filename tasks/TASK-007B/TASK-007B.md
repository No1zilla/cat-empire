## 🎯 Описание подзадачи

В модальном окне офлайн-дохода `OfflineModal.js` при возврате игрока в игру показывать две опции:
1. **«👛 Забрать!»** — забрать базовую сумму оффлайн-монет (`earnedCoins`).
2. **«🎬 Забрать 2x за Видео»** — просмотр 5-секундной рекламы удваивает оффлайн-награду (`earnedCoins * 2`).

---

## 🛠 Задачи для разработчика

1. Обновить `OfflineModal.js`: добавить вторую акцентную зелёную кнопку «🎬 Забрать 2x за Видео».
2. При нажатии вызывать `AdModal` рекламы.
3. По завершении просмотра начислять игроку `earnedCoins * 2` и вызывать `saveProgress()`.

---

## ✅ Критерии приёмки

- [ ] В `OfflineModal.js` присутствуют обе кнопки: обычный забор и забор 2x за рекламу.
- [ ] При клике на «🎬 Забрать 2x» открывается модальное окно рекламы.
- [ ] После просмотра на баланс зачисляется удвоенная сумма монет.
