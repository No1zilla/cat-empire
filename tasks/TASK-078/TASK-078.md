## Фантазия

Кото-Бог видит, что империя только встала на лапы, и кидает к ногам **ларец первого трона**. Это не скидка в магазине, а дар: «возьми и правь». Повторно ларец не падает — боги не щедры дважды.

## Зачем

Три пака в магазине — витрина. $10k требуют **конверсию в первый платёж**. Ларец дороже по рубинам, чем «Супер», дешевле по ощущению («успей»). Без него платят единицы.

## Оффер (один раз)

| | Значение |
|---|---|
| id | `starter_tribute_5` |
| Цена | **5 голосов** |
| Внутри | **80 рубинов** + бустер 2× на **60 мин** |
| Показ | поле полно / 0 рубинов на «Соединить» / первый Кото-Бог — что раньше |
| Повтор | флаг `starter_tribute_claimed`; больше не показывать |

Сравнение: «Супер» = 50/4. Ларец = 80+час 2× / 5 → выглядит как милость, не как грабёж.

## Поток

1. Условие сработало → модалка «Ларец первого трона», не общий магазин.
2. Кнопки: **Открыть ларец** (оплата) / **Потом** (закрыть, можно вернуть 1 раз из магазина плашкой).
3. Оплата `VKWebAppShowOrderBox` → зачисление только после успеха.
4. Тост: «Кото-Бог дал ларец. +80 рубинов и час ×2».
