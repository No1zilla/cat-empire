# 📌 TASK-030: Режим «Кошачьи Экспедиции» (Expeditions)

> **Статус:** 🟡 В очереди
> **Приоритет:** Средний

---

## 🎯 Описание задачи
Дать игроку возможность отправлять высокоуровневых котиков в экспедиции на время за сундуками сокровищ и редкими наградами.

---

## 🛠 Задачи:
1. Создать окно «Кошачьи Экспедиции».
2. Выбор котика для отправки в поход (на 1ч, 4ч, 8ч).
3. Таймер возвращения котика с добычей.
4. Награды: Сундуки с гемами, купоны на скидку покупок, аксессуары.
