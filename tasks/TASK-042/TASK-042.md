# 📌 TASK-042: Аудит и фикс синхронизации прогресса (правило VK 2.3.8)

> **Статус:** 🔴 Критический (блокирует модерацию VK)
> **Приоритет:** P0 — без этого приложение не пройдёт модерацию
> **Зависимости:** нет

---

## 🎯 Проблема

Модерация VK отказывает в публикации по правилу **2.3.8**:
> «Приложение должно синхронизировать прогресс Пользователя в Приложении между версиями, предназначенными для разных платформ.»

**Тест-кейс (воспроизведение):**
1. Открыть игру на ПК (vk.com/app54692477)
2. Открыть игру на телефоне (VK Android)
3. Сделать мердж котиков на телефоне
4. Обновить страницу на ПК → **прогресс НЕ синхронизируется** ❌

---

## 🔍 Корневые причины (Root Cause Analysis)

### БАГ 1: `_saveToLocalStorage()` пишет только в localStorage, минуя VK Storage
**Файл:** `src/game/Game.js:394-413`

Метод `_saveToLocalStorage()` напрямую пишет в `localStorage`, а затем вызывает `syncManager.scheduleSave()`, который через 800мс вызывает `storageService.saveProgress()`. Но на мобильных VK-клиентах:
- **Дебаунс 800мс может не успеть выполниться**, если пользователь быстро свернул приложение
- **`visibilitychange` на мобильных VK не всегда срабатывает** — VK iframe может быть убит iOS/Android без события

**Решение:** Мердж-события и покупки должны немедленно сохраняться в VK Storage, без ожидания дебаунса.

---

### БАГ 2: `loadProgress()` НЕ перезагружает данные при `visibilitychange` (focus)
**Файл:** `src/game/Game.js:416-431`

Когда пользователь возвращается к открытой вкладке на ПК — игра **НЕ перечитывает облачное состояние**. Она показывает то, что загрузила при первом старте. Нет обработчика «вкладка стала видимой → подтянуть свежие данные из облака».

**Решение:** При `document.visibilityState === 'visible'` выполнять `storageService.loadProgress()` и обновлять игровое состояние.

---

### БАГ 3: VK Storage `storageSet` тихо падает из-за лимита размера (10 000 символов)
**Файл:** `src/vk/VKBridge.js:79-92`

`VKWebAppStorageSet` ВКонтакте имеет ограничение **10 000 символов на значение**. Если `gridState` содержит 25 ячеек с полными данными — JSON может превысить лимит, и `storageSet` тихо вернёт ошибку, которую мы игнорируем (`catch` пустой).

**Решение:** Компактная сериализация `gridState` (только `slotIndex` + `catLevel`), логирование ошибок VK Storage.

---

### БАГ 4: Авто-сохранение каждые 30 сек использует `saveProgress()` API напрямую, минуя `storageService`
**Файл:** `src/game/Game.js:375-390`

Авто-сохранение (интервал 30 сек) вызывает API `saveProgress()` напрямую из `client.js`, **минуя** `StorageService.saveProgress()`, и поэтому **НЕ пишет в VK Cloud Storage**.

**Решение:** Заменить прямой вызов `saveProgress()` на `storageService.saveProgress()`.
