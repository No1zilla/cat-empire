## 🛠 Задачи для разработчика (По стандартам скиллов):

### 1. Эффект спецэффектов при Merge (`MergeEngine.js` / `Cat.js`)
*(Скилл `ui-ux-design`: Particle FX & Motion)*
- [ ] При успешном объединении двух котиков создавать всплеск золотых звёздочек/искр (Particle Burst) в точке слияния.
- [ ] Добавить короткую вспышку (Flash glow) в месте спавна нового кота.

### 2. Рамка игрового поля (`Grid.js`)
*(Скилл `antigravity-design-expert`: Glassmorphism & Soft Depth)*
- [ ] Обернуть всю сетку 5×5 в элегантную внешнюю монолитную рамку (Board Frame) с подложкой матового стекла, тонкой светлой обводкой `rgba(255,255,255,0.15)` и градиентной тенью.

### 3. Аура для редких котиков (`Cat.js`)
*(Скилл `game-ui-hud-designer`: Rarity Visual System)*
- [ ] Для котиков 5+ уровня добавлять под пьедестал пульсирующий круг свечения (Aura Glow):
  - Lvl 5–8: Фиолетовое свечение (Редкий)
  - Lvl 9–12: Золотое свечение (Эпический)
  - Lvl 13–15: Радужное / Бриллиантовое свечение (Легендарный)

### 4. Анимация кнопки покупки (`AutoMergeButton.js` / `main.js`)
*(Скилл `antigravity-design-expert`: Spring Dynamics & CTA Accent)*
- [ ] Когда на балансе игрока достаточно монет для покупки котика, кнопка «Купить» должна медленно «дышать» (пульсировать scale `1.0 -> 1.04 -> 1.0` каждые 1.5 сек), привлекая внимание.

### 5. Тактильный отклик VK Haptics & Текст Дохода (`VKBridge.js` & `DragSystem.js`)
*(Скилл `ui-ux-design`: Haptic Feedback & Dynamic HUD)*
- [ ] При отпускании кота и успешном мердже вызывать вибрацию через VK Bridge:
  `bridge.send('VKWebAppTapticImpactOccurred', { style: 'medium' });`
- [ ] Добавить бегущие циферки дохода (`+13.8K` зелёным цветом, всплывающие вверх и исчезающие над котиками раз в секунду).
