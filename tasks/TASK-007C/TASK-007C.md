# 📌 TASK-007C: Кнопка фарма гемов «🎬 +5 💎» в HUD

> **Статус:** 🟡 В очереди
> **Приоритет:** Средний (P2 — фарм премиум-валюты)
> **Зависимости:** TASK-005, TASK-047

---

## 🎯 Описание подзадачи

Добавить в плашку шапки `HUD.js` рядом с балансом гемов пульсирующую иконку-кнопку **«🎬 +5 💎»** для игроков, которые хотят явно фармить гемы просмотром рекламы.

---

## 🛠 Задачи для разработчика

1. Обновить `HUD.js`: рядом с капсулой гемов добавить кнопку `+5 💎`.
2. При клике открывать `AdModal` с `rewardGems = 5`.
3. После успешного просмотра зачислять `+5 💎` на баланс `economy.addGems(5)` и вызывать `saveProgress()`.

---

## ✅ Критерии приёмки

- [ ] Кнопка «🎬 +5 💎» отображается в верхнем меню игры.
- [ ] При клике открывается рекламный плеер.
- [ ] За просмотр игроку зачисляются ровно 5 гемов на баланс.
