# 📌 TASK-007C: Кнопка «+5 рубинов» в шапке

> **Статус:** ✅ КОД НА `/dev/`  
> **Приоритет:** P1 — добровольный фарм показов  
> **Валюта:** рубины, ровно +5

---

## Цель

Игрок, которому нужны рубины, жмёт в шапке и смотрит ролик. Не прячет фарм только в «Соединить».

## Реализация

1. В HUD рядом с капсулой рубинов — кнопка «+5» (иконка рубина, не голубой 💎).
2. Клик → `AdModal` / native ads, `rewardGems = 5`.
3. Успех → `economy.addGems(5)` + `saveProgress()`.
4. Закрыли ролик / отмена → рубины не капают.
5. Если рекламы нет — инвайт друзей за +5 рубинов (как сейчас).

## Критерии

- [x] Кнопка видна в шапке
- [x] За просмотр ровно +5 рубинов
- [x] Тост без эмодзи 💎: «+5 рубинов»
- [x] Сборка на `/dev/`
