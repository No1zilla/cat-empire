# 📌 TASK-D01: Регистрация VK Mini App

> **Статус:** 🟢 Выполнено
> **Время:** 10–15 минут (ручные действия на сайте VK)
> **Зависимости:** Нет

---

## 🎯 Цель

Зарегистрировать приложение на платформе VK Mini Apps. Получить `app_id` и `client_secret`, которые нужны для бэкенда (проверка подписи) и фронтенда.

---

## 📋 Пошаговая инструкция (ручные действия)

### Шаг 1: Создать приложение

1. Открой [vk.com/editapp?act=create](https://vk.com/editapp?act=create)
2. Выбери тип: **VK Mini Apps**
3. Название: `Империя Котиков`
4. Нажми **Подключить приложение**

### Шаг 2: Сохрани данные

После создания запиши два значения — они нужны в следующих задачах:

```
APP_ID      = 54692477
APP_SECRET  = <секрет — только в переменных окружения, не в репозитории>
```

### Шаг 3: Настройки приложения

В разделе **«Настройки»**:

| Поле | Значение |
|------|----------|
| Тип приложения | VK Mini Apps |
| Статус | **Включено** |
| Адрес сайта | *(заполним в TASK-D03 после деплоя)* |

### Шаг 4: Обнови .env бэкенда

Открой файл `cat-empire/server/.env` и вставь полученные данные:

```env
DATABASE_URL="file:./dev.db"
PORT=3001
VK_APP_SECRET=<секрет — только в переменных окружения, не в репозитории>
```
