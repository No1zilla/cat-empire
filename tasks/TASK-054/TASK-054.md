# 📌 TASK-054: Блокировка вызова оффлайн-дохода для новичков и при сбросе прогресса

> **Статус:** ✅ ВЫПОЛНЕНО И ВЕРИФИЦИРОВАНО
> **Приоритет:** Высокий (P1 — исправление инфляционного взрыва монет)

---

## 🎯 Описание проблемы
При запуске игры на мобильных устройствах игрокам начислялись 3.5 миллиона монет из-за срабатывания `OfflineEarningsModal`, посчитавшего доход от старого облачного прогресса за 2 часа отсутствия.

---

## 🛠 Выполненные решения
1. В `Game.js` установлена проверка `isBeginner = (maxCatLevel <= 1 && totalMerges <= 10)`.
2. Для всех новичков и сброшенных профилей показ `OfflineEarningsModal` при входе заблокирован.

---

## ✅ Критерии приёмки
- [x] Игроки с 1 уровнем котиков не получают модалку офлайн-дохода.
- [x] После сброса прогресса стартовый баланс равен ровно 100 монет.
