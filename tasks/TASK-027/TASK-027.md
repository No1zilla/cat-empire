# 📌 TASK-027: Празднование 15-го уровня и экран «Божественного Вознесения»

> **Статус:** 🟡 В очереди
> **Приоритет:** Высокий

---

## 🎯 Описание задачи
Реализовать кульминационный момент достижения 15-го уровня («Кото-Бог»). При слиянии до 15 уровня игрок должен получать вау-эффект, торжественную анимацию салюта и ценные награды.

---

## 🛠 Задачи:
1. Создать праздничное модальное окно победы при открытии 15-го котика.
2. Добавить анимированный салют / конфетти на всю ширину экрана (Pixi / Canvas particles).
3. Выдавать награду: **+500 Гемов 💎** и уникальный божественный аватар/бейдж.
4. Добавить кнопку перехода к Ритуалу Перерождения (TASK-028).
