> **Статус:** 🟢 Завершено

> **Зависимости:** TASK-005

---

## 🎯 Проблема и Диагноз

Сейчас на скриншоте:
- Доход: `435 монет/сек`
- Цена покупки 1-го котика: `2 524 107 монет`
- **Время ожидания покупки 1 котёнка:** **1.5 часа (!)** 

### Причины бага баланса:
1. **Жёсткая инфляция (`1.15^N`):** При 90+ покупках цена 1-го уровня выросла в 250 000 раз.
2. **В магазине продаются только коты 1-го уровня:** Чтобы сделать 9-й уровень, нужно объехать 256 котят 1-го уровня, выкручивая инфляцию на максимум.
3. **Рассогласование графиков:** Инфляция покупок опережает рост дохода в десятки раз.

---

## 📐 Решение по стандартам мировых Merge-игр (*Merge Plane*, *Cat Condo*)

### 1. Смягчение коэффициента инфляции (`Economy.js`)
- Снизить инфляционный множитель с `1.15` до `1.07`.
- **Формула стоимости Lvl 1:** `Math.floor(10 * Math.pow(1.07, totalCatsBought))`

### 2. Динамический кап времени покупки (Target TTB - Time To Buy)
- Котик **1-го уровня** НЕ ДОЛЖЕН стоить дороже **30 секунд** текущего дохода игрока.
- Добавить в `getCatCost()` ограничение:
  `cost = Math.min(calculatedCost, incomePerSecond * 30)` (но не меньше стартовых 10 монет).

### 3. Механика Smart Shop (Покупка прокачанных котиков)
- Как только игрок открывает котика уровня `N` (например, Lvl 8):
  - В магазине открывается возможность покупать котика уровня `Math.max(1, N - 4)` (например, Lvl 4)!
  - Игроку больше не нужно кликать 200 раз 1-й уровень — он сразу покупает 4-й уровень за справедливую цену.

## 🛠 Изменения в коде для разработчика:

### В `Economy.js`:
```javascript
getCatCost() {
  const baseCost = Math.floor(10 * Math.pow(1.07, this.totalCatsBought || 0));
  // Ограничиваем стоимость 1-го кота: не более 30 сек пассивного дохода
  const maxCap = Math.max(10, (this.incomePerSecond || 0) * 30);
  return Math.min(baseCost, maxCap);
}
```

### В `SpawnSystem.js` / `Shop`:
- Добавить авто-сброс цены котиков 1-го уровня при переходе на новые этапы или возможность покупать кота уровня `MaxLevel - 3`.

## ✅ Критерии приёмки
- Стоимость котика 1-го уровня никогда не превышает 30 секунд накопления монет.
- Игрок снова может активно играть, покупая котиков каждые 15–20 секунд.
- При открытии котиков 6+ уровня покупка становится адекватной по времени.
