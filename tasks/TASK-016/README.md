### 2. ⏱️ Кап Target TTB — Time To Buy (не более 30 секунд)
- Добавлено жесткое ограничение `maxCap`: стоимость покупки котика в магазине **НИКОГДА НЕ ПРЕВЫШАЕТ 30 секунд** пассивного дохода игрока:
  ```javascript
  const maxCap = Math.max(10, Math.floor(incomePerSecond * 30));
  return Math.min(baseCost, maxCap);
  ```
- **Результат:** Время накопления монет на следующую покупку всегда адекватно (не более 15–30 секунд динамичной игры вместо 1.5 часов ожидания).

---

### 3. 🛍️ Механика Smart Shop (`SpawnSystem.js` & `Game.js`)
- При развитии империи (открытии 5+ уровня) магазин автоматически переключается на продажу прокачанных котиков уровня **`Math.max(1, maxCatLevel - 3)`**.
- При Lvl 5 продаётся Lvl 2, при Lvl 8 сразу продаётся Lvl 5!
- Текст кнопки автоматически обновляется: `🐱 Lvl N (X 🪙)`.
- Игроку больше не нужно делать 256 кликов 1-го уровня.
