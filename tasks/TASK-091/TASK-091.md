# 📌 TASK-091: Серый кружок вместо монеты — эмодзи 🪙 вшит в текст вместо `createCoinIcon`

> **Статус:** 🔴 Не начато
> **Приоритет:** P2 — видно игроку в модалке ежедневного подарка, ломает «Стиль — закон»
> **Зависимости:** нет

---

## Симптом

В модалке «🎁 ЕЖЕДНЕВНЫЙ ПОДАРОК» награда за День 1 показана как `500 🌑` — вместо золотой монеты серый кружок. То же на кнопке «ЗАБРАТЬ • 500 🌑» и в Дне 4 (`2 500`).

## Причина

В подписи зашит **эмодзи `🪙`** (U+1FA99 COIN, Emoji 13.0, 2020 год):

```js
// src/game/DailyRewards.js:7
{ day: 1, coins: 500, gems: 0, catLevel: 0, label: '500 🪙' },
```

Шрифт Fredoka этого глифа не содержит, PixiJS уходит в системный фолбэк и рисует унылый серый кружок вместо монеты.

Это прямо противоречит правилу из `GEMINI.md` → «Стиль (не ломать)»:

> Рубины: `createGemIcon` + `formatRubies`, **никогда 💎**

Для монет действует ровно тот же принцип, и в проекте уже есть `UIUtils.createCoinIcon(radius)` — рисованная объёмная золотая монета. Ей корректно пользуются **7 мест**: `HUD.js:89`, `OfflineModal.js:101`, `OfflineEarningsModal.js:124`, `FillAllButton.js:85,235`, `CatDetailModal.js:177`, `SpawnSystem.js:38`.

## Все места утечки эмодзи (не только подарок)

| Файл | Строка | Текст |
|---|---|---|
| `src/game/DailyRewards.js` | 7 | `'500 🪙'` |
| `src/game/DailyRewards.js` | 10 | `'2 500 🪙'` |
| `src/ui/FillAllButton.js` | 267 | `'Мало 🪙!'` |
| `src/game/Game.js` | 224 | `'Мало 🪙!'` |
| `src/game/SpawnSystem.js` | 240 | `'Мало 🪙!'` |

Тосты «Мало 🪙!» дают тот же серый кружок — просто мелькают быстрее и в глаза не бросались.

## Как чинить

Награда должна нести **данные**, а не готовую строку с картинкой. В `DailyRewards.js` уже есть поля `coins` / `gems` / `catLevel` — подпись можно собирать из них, а иконку класть отдельным объектом.

1. Убрать `🪙` из `label`, оставить число (`'500'`, `'2 500'`). Поля `coins`/`gems` уже есть — тип награды из них выводится.
2. В [`DailyRewardsModal.js:110`](../../src/ui/DailyRewardsModal.js) (карточка дня) и [`:155`](../../src/ui/DailyRewardsModal.js) (кнопка «ЗАБРАТЬ») дорисовывать `UIUtils.createCoinIcon()` рядом с текстом, если `reward.coins > 0` — как это делает `FillAllButton.js:85`, там иконка ставится рядом с ценой на кнопке.
3. Карточки дней узкие — проверить, что число + иконка влезают и не наезжают на рамку.
4. Тосты «Мало 🪙!» → текст без эмодзи («Мало монет!») либо тост с иконкой, если `UIUtils.showToast` умеет принимать `Container`.
