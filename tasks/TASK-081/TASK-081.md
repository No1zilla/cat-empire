# 📌 TASK-081: Созыв вассалов

> **Статус:** ⬜ После перелёта на землю 2 (TASK-076)  
> **Приоритет:** P2 — DAU, не касса  
> **Награда:** +10 рубинов **один раз** за реальный инвайт с экрана победы

---

## Фантазия

Империя взяла новую землю. Кото-Бог велит **созвать вассалов**: «Пусть придут коты с соседних дворов». Это не вечная кнопка «Друзья» в меню, а момент славы — один раз после первого перелёта.

## Зачем

Инвайт из меню (+5) слабый: его некогда жать. Вирус нужен в точке эмоции (только что улетели). +10 и картинка «Земля 2 взята» конвертят лучше, чем ещё один пункт меню.

## Поток

1. Первый успешный перелёт на землю 2 → после тоста «Новая территория» модалка **«Созвать вассалов»**.
2. Кнопка `VKWebAppShowInviteBox`. Успех и не `simulated` → **+10 рубинов**, флаг `vassals_summoned`.
3. «Позже» закрывает. Повторно модалку не навязывать; в меню остаётся обычный инвайт +5.
4. Не выдавать +10 за фейковый инвайт вне VK.

## Критерии

- [ ] Модалка только после первого перелёта
- [ ] +10 рубинов один раз, тост без 💎
- [ ] Отмена = 0
- [ ] Событие `vassals_summoned`
- [ ] Сборка на `/dev/`
