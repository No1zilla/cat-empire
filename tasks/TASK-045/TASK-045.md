## 🎯 Цель

Опубликовать «Империю Котиков» в RuStore до Google Play:
- Меньше конкуренции → выше органический трафик
- Бесплатная публикация
- Комиссия с IAP: 15% (против 30% у Google Play)
- Реальный шанс на редакционный фичеринг от команды RuStore

---

## 🛠 Шаги публикации

### 1. Регистрация разработчика (rustore.ru/developers)
- [ ] Зарегистрироваться на rustore.ru/developers
- [ ] Пройти верификацию: паспорт / ИНН (для физлица или ИП)
- [ ] Подписать оферту — бесплатно
- [ ] Срок: **1–3 рабочих дня**

### 2. Подготовка приложения
- [ ] Package name: `ru.catempire.app` (или аналог)
- [ ] Подписать APK/AAB тем же ключом что и для Google Play (один keystore)
- [ ] Target SDK: минимум Android 8.0 (API 26)
- [ ] Добавить разрешения: `INTERNET`, `VIBRATE`

### 3. Интеграция RuStore SDK (вместо Google Play Billing)
- [ ] Подключить `ru.rustore.sdk:billingclient` для IAP
- [ ] Подключить `ru.rustore.sdk:pushclient` для Push-уведомлений (опционально)
- [ ] Документация: https://help.rustore.ru/rustore/developers/sdk

### 4. Реклама внутри приложения (вместо AdMob)
- [ ] Подключить VK Ads SDK (MyTarget) для Rewarded Video
- [ ] `implementation 'com.my.target:mytarget-sdk:5.x.x'`
- [ ] eCPM ожидаемый: 80–200 ₽

### 5. Графические материалы для страницы RuStore
Все уже есть в нашем промо-паке:
- [ ] Иконка: `vk_icon_512x512.png` (нужна 512×512, нарезать из 576×576)
- [ ] Скриншоты: 5 вертикальных 1080×1920
- [ ] Баннер: 1920×1080
- [ ] Описание: взять из README.txt промо-пака

### 6. Подача на модерацию
- [ ] Категория: «Игры → Казуальные»
- [ ] Возрастной рейтинг: 3+ (нет жестокости, нет азартных игр)
- [ ] Срок модерации RuStore: **2–5 рабочих дней**

### 7. Запрос фичеринга (Редакционное продвижение)
- [ ] Написать в support@rustore.ru с темой «Запрос на фичеринг — Империя Котиков»
- [ ] Приложить: описание, скриншоты, ссылку на приложение
- [ ] RuStore активно ищет качественные российские игры → шанс попасть в «Рекомендованные» реален
