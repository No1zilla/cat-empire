## 🛠️ Описание возникших проблем и их решение

1. **Блокировка кликов под модальным окном**:
   - *Проблема*: Элементы игрового поля под модальным окном могли быть случайно нажаты до закрытия всплывающего окна.
   - *Решение*: Для фонового графического элемента `overlay` установлен режим `eventMode = 'static'`, что изолирует клики от нижних слоёв сцены PixiJS.
