# 📌 TASK-020: 7-Дневный Календарь Подарков (Daily Login Rewards)

> **Статус:** 🟡 В очереди
> **Приоритет:** Высокий (D7 Retention Booster)
> **Зависимости:** TASK-005, TASK-006

---

## 🎯 Цель

Внедрить систему ежедневных наград за запуск игры 7 дней подряд. Это ключевая механика удержания игроков (Retention), заставляющая возвращаться каждый день.

---

## 🎁 Награды по дням:

| День | Награда |
|------|---------|
| **День 1** | `500 🪙` монет |
| **День 2** | `10 💎` гемов |
| **День 3** | Кот 3-го уровня |
| **День 4** | `2,500 🪙` монет |
| **День 5** | `25 💎` гемов |
| **День 6** | Кот 5-го уровня |
| **День 7** | 🏆 **Уникальный Кот-Бонус (Lvl 7) + 50 💎** |

---

## 🛠 Задачи для разработчика (`DailyRewardsModal.js`):
- [ ] При каждом первом входе за день открывать окно «Ежедневный подарок».
- [ ] Отображать 7 карточек с подарками. Подсвечивать текущий день.
- [ ] Кнопка «Забрать подарок» списывает награду в `Economy` и сохраняет дату в профиль.
- [ ] Добавить кнопку *«Удвоить подарок за просмотр видео»* (задел под рекламу).

---

## ✅ Критерии приёмки
- При входе на следующий день открывается модалка наград.
- Игрок получает монеты, гемы и котиков за регулярные заходы.
