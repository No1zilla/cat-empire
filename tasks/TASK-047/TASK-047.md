# 📌 TASK-047: Game Field UI — Стандартизация Тёмного Игрового Поля

> **Статус:** 🟡 В очереди
> **Приоритет:** Высокий (визуальная целостность)
> **Зависимости:** TASK-046 (design-tokens)

---

## 🎯 Проблема

Игровое поле имеет красивых котиков и удачную тёмную тему, но управляющие кнопки разномастны по цветам («Купить» — красный, «Заполнить» — оранжевый, «Соединить» — фиолетовый), а стили компонентов заданы хаотично.

---

## 🛠 Что сделать

### 1. Унификация кнопок управления снизу
- [ ] Кнопка **«Купить»** — оставляет статус главной CTA-кнопки (коралово-розовый градиент `#FF5E7E → #FF3B60`).
- [ ] Кнопки **«Заполнить»** и **«Соединить»** — перевести на единый второстепенный фиолетовый стиль (`#6B46C1 → #553C9A`).
- [ ] Привести все 3 кнопки к одинаковой высоте, скруглению (`20px`) и единой типографике.

### 2. Приведение UI-элементов к токенам
- [ ] Верхний HUD (Монеты / Гемы / Доход) — привести подложки к единому стилю карточек (`#150E33` с аккуратным бордюром `#2E2263`).
- [ ] Полоса Котопедии внизу — оформить в едином стиле темных плашек `#150E33`.
- [ ] Сетка ячеек — сохранить тёмный фон `#1A123D`, вынести цвета в `design-tokens.js`.

---

## ✅ Критерии приёмки
- [ ] Сохранён привычный тёмный вид игры.
- [ ] Кнопки действий выглядят как элементы единой дизайн-системы.
- [ ] Код не содержит разрозненных хардкод-цветов.
