# 📌 TASK-074: Вступление в группу VK за +5 рубинов

> **Статус:** ⬜ После идола / вместе с созывом вассалов — рост, не касса  
> **Приоритет:** P2  
> **Валюта:** +5 рубинов, один раз

---

## Фантазия

Двор империи — паблик VK. Кто вошёл во двор, получает пайку рубинов. Это не касса, это люди, которым потом можно сказать «вышла земля 2».

## Цель

Разовый бонус за вступление в официальную группу. Нужен реальный `group_id` паблика.

## Поток

1. Плашка в меню: «Двор империи (+5 рубинов)».
2. `VKWebAppJoinGroup` с `group_id` сообщества.
3. Успех → +5 рубинов, флаг `community_joined`.
4. Повторно не начислять.

## Критерии

- [ ] Кнопка «Двор империи» в меню, без голубого 💎
- [ ] Успех → +5 рубинов один раз
- [ ] Отмена / уже в группе без флага — без начисления, если VK не подтвердил
- [ ] `community_joined` в аналитике
- [ ] Сборка на `/dev/`

## Стиль — как сейчас в игре

Кнопка в главном меню как «РУБИНЫ» / «ДРУЗЬЯ»: `UIUtils.createButton`, тот же ряд, рубин `createGemIcon`, без 💎. Подробно: PLAN.md → «Стиль — закон».
