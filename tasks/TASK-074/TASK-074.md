# 📌 TASK-074: Награда +15 💎 за Вступление в Официальное Сообщество VK (`VKWebAppJoinGroup`)

> **Статус:** 🔲 В ОЧЕРЕДИ
> **Приоритет:** Высокий (P1 — Набор подписчиков в группу игры VK)
> **Зависит от:** TASK-015B, TASK-066 (EventTracker)

---

## 🎯 Цель
Предоставить игроку разовый крупный бонус в **+15 гемов** (хватит на 3 авто-слияния) за вступление в официальное сообщество игры ВКонтакте через метод `VKWebAppJoinGroup`.

---

## 📐 Игровая Механика и Дизайн

### 1. Поток взаимодействия
1. При 0 гемов на ПК или в главном меню появляется плашка **«👥 Вступи в группу VK (+15 💎)»**.
2. При клике вызывается `VKWebAppJoinGroup` с `group_id` вашего паблика.
3. После подписки сервер/клиент проверяет факт вступления и начисляет **+15 💎**.
4. Кнопка получает статус «ВЫПОЛНЕНО ✅».

---

## 🛠 Реализация

### 1. Вызов VK Bridge (`src/vk/VKBridge.js`)
```javascript
async joinCommunity(groupId = 220000000) {
  try {
    const res = await this.bridge.send('VKWebAppJoinGroup', { group_id: groupId });
    return { success: true, res };
  } catch (e) {
    return { success: false, error: e };
  }
}
```

### 2. Сохранение прогресса
- Флаг `community_joined = true` сохраняется в `StorageService` и на бэкенде, предотвращая повторное начисление.

---

## ✅ Критерии приёмки
- [ ] Окно подписки предлагает вступить в группу за +15 💎.
- [ ] При успешном вступлении зачисляются +15 гемов.
- [ ] Повторное получение блокируется флагом `community_joined`.
- [ ] Аналитика трекает `eventTracker.track('community_joined', { reward_gems: 15 })`.
