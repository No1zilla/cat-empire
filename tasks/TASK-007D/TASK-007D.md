# 📌 TASK-007D: Бустер «🚀 2x Пассивный Доход (30 мин)» за рекламу

> **Статус:** 🟡 В очереди
> **Приоритет:** Высокий (P1 — основной временный бустер вовлеченности)
> **Зависимости:** TASK-005, TASK-016

---

## 🎯 Описание подзадачи

Реализовать временный ракето-бустер пассивного дохода, удваивающий параметр `incomePerSecond` на 30 минут за 1 просмотр видеоролика.

---

## 🛠 Задачи для разработчика

1. Создать компонент иконки бустера `IncomeBoosterButton.js` на главном экране с таймером обратного отсчета (`29:59`).
2. При клике запускать `AdModal`.
3. По завершении просмотра устанавливать `incomeMultiplier = 2` на 30 минут (1800 секунд).
4. Сохранять время окончания действия бустера `boosterExpiresAt` в `storageService`.

---

## ✅ Критерии приёмки

- [ ] Иконка ракето-бустера отображается на игровом поле.
- [ ] После просмотра рекламы значение `+N/сек` в HUD удваивается.
- [ ] Таймер отсчитывает 30 минут, после чего умножитель сбрасывается обратно до 1x.
