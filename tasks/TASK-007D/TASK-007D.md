# 📌 TASK-007D: Бустер 2× пассивный доход на 30 мин за рекламу

> **Статус:** ✅ КОД НА `/dev/`  
> **Приоритет:** P1 — станок показов и повторных заходов  
> **Валюта / награда:** не рубины, а ×2 к доходу

---

## Цель

Игрок смотрит ролик → доход сетки ×2 на 30 минут → когда таймер кончился, снова жмёт. Это и показы, и retention внутри дня.

## Реализация

1. Кнопка на поле: «🚀 2× 30 мин».
2. Клик → тот же рекламный поток, что «Соединить» без рубинов (`AdModal` / native ads).
3. Успех → `incomeMultiplier = 2` до `boosterExpiresAt = now + 1800_000`.
4. HUD `+N/сек` показывает удвоенное значение, на кнопке таймер `29:59`.
5. Сохранить `boosterExpiresAt` в `localStorage` (`cat_empire_booster_expires_at`). После перезапуска бустер живой, если время не вышло.
6. Истечение → множитель 1×, кнопка снова зовёт ролик.

## Критерии

- [x] Кнопка видна на игровом поле
- [x] После ролика `+N/сек` ×2
- [x] Таймер 30 мин, потом сброс
- [x] Бустер переживает рестарт приложения
- [x] Закрытый / недосмотренный ролик бустер не включает
- [x] Сборка на `/dev/`
