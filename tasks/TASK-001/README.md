# Артефакт выполнения задачи TASK-001: VK Мини-приложение «Империя Котиков»

## Описание задачи
Создание базового проекта VK мини-приложения на базе Vite, PixiJS v8, `@vkontakte/vk-bridge` и Vanilla JS (ES modules).

---

## 📁 Созданная структура файлов

```
cat-empire/
├── index.html              — минимальный HTML5 с подгрузкой main.js и тёмным фоном #1a1a2e
├── vite.config.js          — конфиг Vite (base: './', outDir: 'dist', port: 5173)
├── package.json            — зависимости pixi.js (^8.6.6), @vkontakte/vk-bridge (^2.13.0), vite (^6.0.0)
├── public/
│   └── favicon.ico         — иконка 🐱
└── src/
    ├── main.js             — точка входа: асинхронный app.init() PixiJS v8, VK Bridge, монтирование canvas
    ├── config.js            — константы: размеры 400x700, сетка 5x5, палитра цветов, уровни
    ├── game/
    │   └── Game.js          — игровой класс PixiJS v8 (вывод заголовка и имени игрока)
    ├── ui/
    │   └── HUD.js           — класс-заглушка для UI
    └── vk/
        └── VKBridge.js      — обёртка над vk-bridge (init, getUserInfo + mock для локала)
```

## 🛠️ Особенности реализации
1. **PixiJS v8**: Применён асинхронный метод `await app.init(options)`, а холст монтируется через `app.canvas` (вместо `app.view`).
2. **Безопасная обработка VK Bridge**: Вне VK iframe вызовы отлавливаются через `try/catch` и отдают мок-профиль `Тест Игрок`.
