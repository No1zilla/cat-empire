## 🎨 Целевой стиль

**Тема:** Кавайное кошачье королевство — мягкое, яркое, няшное.
**Настроение:** Cute + Cheerful + Cozy. Японский кавай с игровым характером.

### Цветовая палитра (единая для всего проекта):
```
Фон:          #FFF0F8  (нежно-розовый, молочный)
Фон карточек: #FFFFFF  (белый с лёгкой тенью)
Акцент 1:     #FF6B9D  (кавайный розовый) — заголовки, CTA-кнопка
Акцент 2:     #A78BFA  (лавандовый) — вторичные кнопки
Акцент 3:     #FFD166  (солнечно-жёлтый) — монеты, бонусы
Текст:        #3D2B4F  (тёмно-пурпурный, мягкий)
Кнопка CTA:   #FF6B9D → #FF9DC8  (розовый градиент)
Кнопка вторич:#A78BFA → #C4B5FD  (лавандовый градиент)
Гемы (💎):    #60C8F5  (голубой)
Монеты (🪙):  #FFD166  (жёлтый)
Успех:        #4ADE80  (мятно-зелёный)
```

### Типографика:
```
Заголовок игры: Fredoka One (Google Fonts) — округлый, весёлый, кавайный
Подзаголовки:   Nunito ExtraBold
UI-текст:       Nunito Bold — кнопки, счётчики
Обычный текст:  Nunito Regular — описания, туториал
```

### Единый стиль кнопок:
- **CTA-кнопка** — розовый градиент, крупная, с bounce-анимацией при появлении
- **Вторичные кнопки** — лавандовый градиент, одинаковые по размеру
- Все кнопки: `border-radius: 24px` (пухлые скруглённые), мягкая тень, hover-scale 1.05
- **Никаких разных случайных цветов** — только розовый и лавандовый

### Главный экран (переработать):
```
[ Фон: нежно-розовый с облачками / звёздочками, мягкий паттерн ]
[ Партиклы: плавающие сердечки ♥, звёздочки ✦, лапки 🐾 ]

🐱 ИМПЕРИЯ КОТИКОВ 👑        ← Fredoka One, розовый + тень
  Идл Мёрдж Королевство      ← Nunito, лавандовый

[ Анимированный логотип: пухлый кот в короне, bounce + float ]

[ ▶ ИГРАТЬ ]                 ← Большая розовая CTA-кнопка
[ 📖 Котопедия ]             ← Лавандовая кнопка
[ ⚙️ Настройки ]             ← Лавандовая кнопка
```
