## 📋 Пошаговая инструкция

### Шаг 1: Деплой на Vercel (Бесплатно)

1. Зайди на [vercel.com](https://vercel.com/) и авторизуйся через GitHub.
2. Нажми **Add New...** → **Project**.
3. Выбери репозиторий `No1zilla/cat-empire`.
4. Настройки проекта:
   - **Framework Preset:** Vite
   - **Root Directory:** `./`
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
5. Нажми **Deploy**.

---

### Шаг 2: Привязка URL к VK Mini App

1. Открой управление приложением ВК: [vk.com/editapp?id=54692477](https://vk.com/editapp?id=54692477)
2. Перейди в **Настройки**.
3. Укажи в полях URL:
   - **URL веб-приложения**: URL фронтенда
   - **Mobile URL**: URL фронтенда

---

### Шаг 3: Тестирование в VK

1. Перейди по прямой ссылке на твоё мини-приложение:
   👉 **[vk.com/app54692477](https://vk.com/app54692477)**
