## Фантазия

Рубины — это сердца империи. Пока в кабинете VK нет товаров и боевых роликов, казна закрыта: игроки видят витрину, а монеты императора не доходят.

## Зачем

Код паков `gems_pack_10 / 50 / 150` уже в игре. Без товаров и callback покупка падает. Без боевой монетизации админ видит тестовые ролики — это нормально, обычный аккаунт должен видеть боевые.

## Сделать вручную

1. Товары приложения VK с теми же id:
   - `gems_pack_10` — 10 рубинов, **1 голос**
   - `gems_pack_50` — 50 рубинов, **4 голоса**
   - `gems_pack_150` — 150 рубинов, **10 голосов**
2. URL уведомлений: `https://cat-empire-production.up.railway.app/api/payments/vk`
3. Передеплой **Railway** с ветки `dev` (иначе `get_item` на старом бэкенде).
4. Включить боевую монетизацию рекламы. Проверка **не** с админского аккаунта.
5. Купить тестовый пак «Старт» с обычного VK → в игре +10 рубинов, в аналитике `iap_purchase_completed`.

## Критерии

- [ ] Три товара в кабинете, цены совпадают с игрой
- [ ] Callback отвечает на `get_item` / `order_status_change`
- [ ] Покупка с телефона и с ПК зачисляет рубины
- [ ] На обычном аккаунте ролик в HUD «+5» — боевой, не тестовый
- [ ] Есть хотя бы одна живая оплата
