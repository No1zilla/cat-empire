# 📌 TASK-007E: Заполнение всех слотов «📦 Заполнить за рекламу»

> **Статус:** 🟡 В очереди
> **Приоритет:** Низкий (P3 — помощь при нулевом балансе монет)
> **Зависимости:** TASK-003, TASK-005

---

## 🎯 Описание подзадачи

В кнопке `FillAllButton.js`, если у игрока не хватает монет для покупки котиков на все пустые слоты, переключать кнопку в режим **«🎬 Заполнить за рекламу»**.

---

## 🛠 Задачи для разработчика

1. В `FillAllButton.js` проверять доступность монет на полную закупку.
2. При недостатке монет отображать альт-режим «🎬 Заполнить за рекламу».
3. При клике запускать `AdModal` рекламы и при успехе спавнить котиков во все свободные слоты без списания монет.

---

## ✅ Критерии приёмки

- [ ] При нехватке монет кнопка переходит в режим за рекламу.
- [ ] Просмотр видео заносит котиков во все доступные свободные слоты сетки.
