## 🛠️ Описание возникших проблем и их решение

1. **Отслеживание `pointermove` при быстром движении**:
   - *Проблема*: При резком перемещении курсора мышь могла выйти за пределы спрайта котика, из-за чего событие `pointermove` переставало генерироваться.
   - *Решение*: Слушатели `pointermove`, `pointerup` и `pointerupoutside` привязаны напрямую к `app.stage`, благодаря чему перетаскивание работает безупречно на любых скоростях.

2. **Сохранение слоя z-order**:
   - *Проблема*: Перетаскиваемый котик мог визуально проходить "под" соседними карточками котиков.
   - *Решение*: В момент `pointerdown` вызывается `this.grid.addChild(cat)`, перемещающий карточку в конец списка отрисовки (на самый верх).
