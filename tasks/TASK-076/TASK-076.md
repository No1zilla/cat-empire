# 📌 TASK-076: Новая территория после Кото-Бога

> **Статус:** ⬜ После кассы (вместе с TASK-028)  
> **Приоритет:** P1 удержание — игрок не «прошёл игру», а улетает дальше  
> **Связано:** TASK-027 (экран Кото-Бога), TASK-028 (мята / постоянный буст)

---

## Фантазия

Империя покорила текущие земли. Кото-Бог открывает портал — **летим на другую территорию играть новыми котиками**. Это не сухой сброс поля, а переезд: другой фон, другая линейка котов 1–15, поле с нуля.

## Зачем для денег

После 15 ур. сейчас тупик. Новый мир даёт второй (третий, N-й) круг merge → снова смотрят рекламу и покупают рубины. Мята из TASK-028 едет с собой, чтобы следующий круг не был тем же гриндом с нуля.

## Поток

1. Слияние до Кото-Бога → текущий экран TASK-027.
2. Вместо только «Слава Кото-Богу» — кнопка **«Лететь на новую территорию»**.
3. Короткий перелёт (2–3 сек): звёзды / карта / смена палитры. Не симулятор рекламы.
4. Старое поле и старые коты этой земли уходят в архив (бейдж «территория покорена»).
5. Старт новой земли: пустое 5×5, цены покупки с нуля, **новый сет котиков 1–15** (имена, цвета, спрайты-заглушки ок, если арта ещё нет).
6. С собой: рубины, мята, номер территории `worldIndex`.
7. На новой земле снова качаемся до своего Кото-Бога → снова перелёт. Повторно.

## Данные в сейве

```
worldIndex          // 1, 2, 3…
worldsCleared       // сколько земель покорено
catLineId           // какой сет котов на текущей земле
mint / prestigeBuff // из TASK-028, не сбрасывать
rubies              // не сжигать
```

## Новый сет котов (черновик, земля 2)

Отдельная таблица, не перетирать землю 1. Примеры слотов:

| Ур. | Имя (земля 2) |
|-----|----------------|
| 1 | Песчаный котёнок |
| … | … |
| 15 | Кото-Бог дюн |

Земля 3 — следующий пак. Пока достаточно **2 сета** (старт + пустыня/неон/космос — выбрать одну палитру).

## UI

- AscensionModal: награда +50 рубинов как сейчас + CTA перелёта
- После перелёта: тост «Новая территория. Новые котики.»
- В меню/HUD мелкий бейдж: «Земля 2»
- Котопедия: вкладки или фильтр по землям, старые коты не пропадают из коллекции

## Не делать в этой задаче

- Экспедиции на таймере (TASK-030)
- Покупка новой земли за голоса
- 15 новых отрисованных спрайтов художником — можно силуэты/перекраска

## Критерии

- [ ] С Кото-Бога можно улететь, а не только закрыть окно
- [ ] После перелёта поле пустое, коты **другие**, фон другой
- [ ] Рубины и мята на месте
- [ ] Котопедия помнит котов предыдущей земли
- [ ] Второй Кото-Бог снова открывает перелёт (земля 3 хотя бы тем же вторым сетом, если третьего нет)
- [ ] Сейв переживает рестарт
- [ ] Сборка на `/dev/`
