# 📌 TASK-075: Магазин рубинов за голоса VK

> **Статус:** ✅ КОД НА `/dev/` — товары в кабинете VK вручную  
> **Приоритет:** P0 — без этого игра не зарабатывает  
> **Валюта в UI:** рубины (не 💎)

## Цель

Игрок может купить рубины за голоса VK. Это единственный прямой рубль с ПК и телефона.

## Паки

| id | Рубины | Голоса |
|----|--------|--------|
| `gems_pack_10` | 10 | 1 |
| `gems_pack_50` | 50 | 4 |
| `gems_pack_150` | 150 | 10 |

## Поток

1. Тап по рубинам в HUD или пункт «Магазин» в меню → окно трёх паков.
2. Клик по паку → `VKWebAppShowOrderBox` `{ type: 'item', item: '<id>' }`.
3. Зачисление **только** после успешного ответа VK, не по клику.
4. Если на «Соединить» 0 рубинов: кнопки **Купить** и **Смотреть рекламу** рядом.

## Кабинет (вручную, до релиза в прод)

- Товары с теми же `item` id в настройках приложения VK.
- Платёжный callback на бэкенд (антифрод чеков).

## Критерии

- [x] Три пака с ценами в голосах, подписи «рубины»
- [x] Виджет оплаты открывается на ПК и на мобайле (`VKWebAppShowOrderBox`)
- [x] Успех → точное число рубинов на баланс + сейв
- [x] Отмена оплаты → рубины не капают
- [x] `iap_purchase_completed` в аналитике
- [x] Сборка на `/dev/`, в прод после проверки в VK
