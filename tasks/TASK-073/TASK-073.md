## 🎯 Цель
Решить проблему отсутствия Rewarded Video на ПК (Десктоп VK): когда у игрока **0 гемов** на ПК, при нажатии «⚡ Соединить» предлагать бесплатно опубликовать открытку с **Зеленоглазой Чёрной Кошечкой** на своей стене VK через `VKWebAppShowWallPostBox` и получить **+5 💎 мгновенно**.

## 📐 Игровая Механика и Дизайн

### 1. Поток взаимодействия (User Flow на ПК)
1. Игрок на ПК нажимает кнопку **«⚡ Соединить»** при балансе **0 гемов**.
2. Ввиду недоступности видеорекламы VK Ads на ПК открывается сочное окно с артом Зеленоглазой Кошечки:
   > **«Закончились рубины? 💎»**
   > *Поделись открыткой с невероятной Зеленоглазой Кошечкой на своей стене ВКонтакте и получи +5 💎 БЕСПЛАТНО!*
3. Кнопка **«📢 Опубликовать на стене VK (+5 💎)»**.
4. Запускается нативный метод `VKWebAppShowWallPostBox` с прикреплением карточки `green_eyes_gift.jpg`.
5. При успешной публикации игрок мгновенно получает **+5 гемов**, происходит авто-слияние котиков, а в аналитику уходит событие `wall_post_reward_granted`.

## 🛠 Реализация

### 1. Фронтенд (`src/ui/DesktopRewardModal.js`)
```javascript
export class DesktopRewardModal extends Container {
  constructor(app, economy, onReward) {
    // Отрисовка сочной карточки с зеленоглазой кошечкой и кнопкой «Опубликовать на стене VK (+5 💎)»
  }

```

### 2. Вызов VK Bridge (`src/vk/VKBridge.js`)
```javascript
async shareWallPostForGems() {
  const res = await this.bridge.send('VKWebAppShowWallPostBox', {
    message: '👀 Посмотрите на эту загадочную Зеленоглазую Кошечку в «Империи Котиков»! Присоединяйтесь к игре!',
    attachments: 'https://vk.com/app54702054'
  });
  return res;
}
```

## ✅ Критерии приёмки
- [ ] На ПК при 0 гемах открывается модалка с артом Зеленоглазой Кошечки.
- [ ] Клик запускает публикацию поста с текстом и ссылкой на приложение VK.
- [ ] Успешный пост начисляет +5 💎 и запускает авто-слияние.
