# 📌 TASK-073: Виральный Пост на Стену VK за +5 Рубинов (Десктоп Fallback при 0 💎)

> **Статус:** 🔲 В ОЧЕРЕДИ
> **Приоритет:** Высокий (P1 — Органический виральный рост VK)
> **Зависит от:** TASK-015B, TASK-066 (EventTracker)

---

## 🎯 Цель
Решить проблему отсутствия Rewarded Video на ПК (Десктоп VK): когда у игрока **0 гемов** на ПК, при нажатии «⚡ Соединить» предлагать бесплатно опубликовать рекорд на своей стене VK через `VKWebAppShowWallPostBox` и получить **+5 💎 мгновенно**.

---

## 📐 Игровая Механика и Дизайн

### 1. Поток взаимодействия (User Flow на ПК)
1. Игрок на ПК нажимает кнопку **«⚡ Соединить»** при балансе **0 гемов**.
2. Ввиду недоступности видеорекламы VK Ads на ПК открывается модальное окно:
   > **«Закончились рубины? 💎»**
   > *Поделись своим рекордом на стене ВКонтакте и получи +5 💎 БЕСПЛАТНО!*
3. Кнопка **«📢 Опубликовать на стене VK (+5 💎)»**.
4. Запускается нативный метод `VKWebAppShowWallPostBox`.
5. При успешной публикации игрок получает **+5 гемов**, происходит авто-слияние котиков, а в аналитику уходит событие `wall_post_reward_granted`.

---

## 🛠 Реализация

### 1. Фронтенд (`src/ui/DesktopRewardModal.js`)
```javascript
export class DesktopRewardModal extends Container {
  constructor(app, economy, onReward) { ... }
}
```

### 2. Вызов VK Bridge (`src/vk/VKBridge.js`)
```javascript
async shareWallPostForGems() {
  const res = await this.bridge.send('VKWebAppShowWallPostBox', {
    message: '🐱 Моя Империя Котиков растёт! Сможешь обогнать мой рекорд?',
    attachments: 'https://vk.com/app54702054'
  });
  return res;
}
```
