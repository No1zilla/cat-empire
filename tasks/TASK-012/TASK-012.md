## 1. src/game/AutoMergeSystem.js

Класс AutoMergeSystem:

constructor(grid, mergeEngine, economy, onStateChange):
- this.grid = grid
- this.mergeEngine = mergeEngine
- this.economy = economy
- this.onStateChange = onStateChange
- this.cooldownTime = 0 // timestamp окончания кулдауна

runAutoMerge():
- Ищет все пары смежных котиков одинакового уровня на сетке.
- Для каждой найденной пары:
  - Вызывает mergeEngine.merge(slotA, slotB).
  - Проигрывает анимацию слияния.
  - Повторяет цикл пока на поле есть хотя бы одна доступная для слияния смежная пара!
- Обновляет состояние сетки и пересчитывает доход:
  - this.economy.recalcAfterMerge()
  - this.onStateChange()

getAvailableMergePairs():
- Сканирует все 25 слотов.
- Возвращает массив пар `[{ slotA, slotB, level }]` смежных котиков с одинаковым уровнем.

## 2. Кнопка ⚡ Авто-Merge в UI

- Кнопка размещается рядом с кнопкой покупки котика: `⚡ Авто-Merge`.
- Состояния кнопки:
  1. **Готово (Бесплатно):** яркая фиолетовая/желтая кнопка `⚡ Авто-Merge`.
  2. **Кулдаун:** пока идет 5 минут — показывает таймер `⏱️ 04:59` или `⚡ 5 💎` для мгновенного применения.
- При клике во время кулдауна:
  - Если у игрока >= 5 гемов -> списать 5 гемов и запустить `runAutoMerge()`.
  - Если гемов < 5 -> показать всплывающую подсказку "Нужно 5 💎".
