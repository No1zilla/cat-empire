# 📌 TASK-060: Устранение конфликта нативной рекламы VK и холста Canvas (Нативное перекрытие)

> **Статус:** ✅ ВЫПОЛНЕНО И ВЕРИФИЦИРОВАНО
> **Приоритет:** Критический (P0 — исправление вылета/зависания нативной рекламы VK)

---

## 🎯 Описание проблемы
На смартфонах в приложении VK вызывалась нативная реклама `VKWebAppShowNativeAds` (интерфейс «Сталинские Соколы / Подробнее» с нативным крестиком VK). Из-за 1.5-секундного таймаута поверх нее холст Canvas одновременно запускал дублирующий симулятор `AdModal`. При клике на нативный крестик VK происходило наложение поверхностных тачей, вызвавшее браузерное выделение и невозможность закрыть окно.

---

## 🛠 Выполненные решения
1. В `AdModal.js` разделены ветви выполнения:
   - В среде VK (`window.vkBridge`) запускается исключительно нативный модуль `_startVkNativeAd()` без создания графических элементов Canvas под нативным окном VK.
   - В локальной веб-среде запускается симулятор `_startSimulatorVideoPlayer()`.
2. При завершении/закрытии/переходе по ссылке из нативного окна VK оверлей `AdModal` закрывается мгновенно (`this._close()`), возвращая игроку чистый интерфейс.

---

## ✅ Критерии приёмки
- [x] В мобильном клиенте VK нативный баннер отрисовывается без дублирующих элементов Canvas под ним.
- [x] Клики по нативному крестику VK сразу закрывают рекламу и возвращают игрока в игру.
