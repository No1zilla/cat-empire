# 📌 TASK-029: Система Ежедневных Квестов и Наград (Daily Tasks)

> **Статус:** 🟡 В очереди
> **Приоритет:** Средний

---

## 🎯 Описание задачи
Внедрить систему ежедневных заданий для повышения удержания игроков (Retention Loop) и выдачи гемов/бустеров.

---

## 🛠 Задачи:
1. Создать интерфейс окна «Ежедневные Задания» (3 случайных квеста в день).
2. Типы квестов:
   - "Соедини N котиков"
   - "Купи N котиков"
   - "Используй авто-соединение N раз"
3. Выдача наград (Гемы 💎 и времнные бусты x2 дохода).
4. Ежедневный таймер сброса заданий.
