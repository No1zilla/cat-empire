## 🎯 Описание проблемы (по скриншоту пользователя)

На реальном устройстве кнопка 🐾 «Меню» визуально:
- **Оторвана от тёмной полосы HUD** — расположена правее конца фонового прямоугольника
- **Имеет явный gap** между капсулой `+2 117/сек` и самой кнопкой
- **Выглядит как floating-кнопка** в правом верхнем углу экрана, не как 4-й элемент строки

### Реальный визуальный результат (скриншот пользователя):
```
[🪙 613 968 987] [💎 6] [+2 117/сек]       🐾
←—— тёмный HUD-бар ————————→    GAP   └── floating
```

### Ожидаемый результат:
```
[🪙 613.3M]  [💎 6]  [+2.1K/сек]  [🐾]
←————————— единый тёмный HUD-бар ——————————→
```

---

## 🔍 Причина

В `HUD.js` метод `_draw()`:

```js
const hudWidth = CONFIG.GAME_WIDTH || 375;
// bg рисуется до 375px

const cap3X = 186;
const cap3W = 124;
// cap3 заканчивается на 310px

const menuBtnX = 314;
const menuBtnW = 44;
// Кнопка: 314→358px — МЕЖДУ cap3 и кнопкой gap 4px
```

На экране VK Mini App canvas масштабируется до реальной ширины viewport (940px в браузере).
При этом PixiJS растягивает canvas, и маленький gap в 4-6px становится заметной дырой.
Плюс — кнопка визуально «отваливается» от тёмного HUD-фона если `hudWidth` не 410px.

---

## 🛠 План исправления

### Шаг 1. Исправить `hudWidth` — фон должен покрывать ВСЕ 4 элемента включая кнопку

```js
// БЫЛО:
const hudWidth = CONFIG.GAME_WIDTH || 375;

// НАДО:
const hudWidth = CONFIG.GAME_WIDTH || 410;
```

### Шаг 2. Убрать gap — сделать кнопку вплотную к cap3

Новая компоновка (hudWidth = 410, padding 6px с каждой стороны):

| # | Элемент    | X   | W   | Конец |
|---|-----------|-----|-----|-------|
| 1 | 🪙 Монеты  | 6   | 130 | 136   |
| 2 | 💎 Гемы    | 140 | 60  | 200   |
| 3 | 📈 Доход   | 204 | 128 | 332   |
| 4 | 🐾 Меню    | 336 | 68  | 404   |

→ 404 + 6 = 410 — заподлицо с правым краем canvas

### Шаг 3. Сделать кнопку 🐾 шире (68px вместо 44px)

Текущая кнопка 44px слишком узкая и выглядит нарочито маленькой относительно капсул (H=34px).
Расширить до 68px — визуально станет пропорциональной капсулой.

### Шаг 4. QA Playwright snapshot viewport=375px

Проверить что все 4 элемента лежат на общем тёмном фоне без разрыва.
