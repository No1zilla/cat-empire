# 📌 TASK-079: Указ семи ночей

> **Статус:** ✅ КОД НА `/dev/` — товар `edict_seven_nights` в кабинете VK  
> **Приоритет:** P1 — повторные деньги, не Battle Pass на 50 ячеек  
> **Валюта:** рубины паёк + вечный 2× на 7 дней

---

## Фантазия

Император издаёт **указ на семь ночей**: пока знамя над площадью, земля сама кормит котов. Это не сезон с сотней квестов. Семь закатов — и указ гаснет. Хочешь ещё — новый указ, новый платёж.

## Зачем

Разовая десятка голосов не держит $10k. Нужен продукт «зайду завтра за пайком». Полный Battle Pass рано: нет контента на 30 ступеней. Семь ночей — проверяем, платят ли за время.

## Продукт

| | Значение |
|---|---|
| id | `edict_seven_nights` |
| Цена | **8 голосов** |
| Сразу | **40 рубинов** |
| 7 дней | доход **×2 постоянно** (складывается с рекламным 2× как max 2, не ×4) |
| Паёк | раз в календарный день кнопка «Забрать указ»: **+8 рубинов** |
| UI | плашка на поле **только паёк**, если указ уже куплен. Покупка — в магазине рубинов. |

Не делать: дерево наград, уровни пропуска, эксклюзивные спрайты художника. Знамя — цвет текста/бейдж «Под указом».

## Поток

1. Магазин: кнопка «Указ семи ночей», если указа нет.
2. Оплата → таймер `edictExpiresAt = now + 7 суток`. На поле появляется паёк.
3. Пока жив: паёк раз в день, 2× на доходе.
4. Истёк → снова продаётся в магазине.

## Критерии

- [ ] 8 голосов → 40 рубинов + 7 дней ×2
- [ ] Паёк +8 рубинов не чаще 1 раза в локальный день
- [ ] После истечения множитель 1×, если нет рекламного бустера
- [ ] Повторная покупка указа работает
- [ ] События `iap_edict_bought`, `edict_daily_claimed`
- [ ] Сборка на `/dev/`
