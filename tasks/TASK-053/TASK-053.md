# 📌 TASK-053: БАГ — Интеграция нативной рекламы VK (VKWebAppShowNativeAds) для кнопки «Соединить»

> **Статус:** 🟡 В РАБОТЕ
> **Приоритет:** P0 — монетизация и функционал рекламных бонусов VK Mini Apps
> **Затронутые файлы:** `src/api/client.js`, `src/ui/AdModal.js`, `src/ui/AutoMergeButton.js`

---

## 🎯 Описание проблемы
При нажатии на кнопку вызова рекламы («🎬 +5 💎» / «Соединить») в веб-версии или мобильном клиенте VK реклама VK не показывается или отклоняется VK Bridge.

## 📋 План исправления
1. **Предварительная проверка VK SDK**: вызвать `VKBridge.send('VKWebAppCheckNativeAds', { ad_format: 'reward' })` перед вызовом `VKWebAppShowNativeAds`.
2. **Обработка событий VK Bridge**: добавить подписку на нативные события VK:
   - `VKWebAppShowNativeAdsResult` (успешный просмотр ролика)
   - `VKWebAppShowNativeAdsFailed` (ошибка или закрытие без просмотра)
3. **Совместимость платформ**: обеспечить поддержку форматов `reward` (мобильные VK клиенты) и `interstitial` (десктоп браузер VK Web).
4. **Интеграция с кнопкой**: верифицировать списание / начисление 5 💎 рубинов и вызов нативного плеера.
