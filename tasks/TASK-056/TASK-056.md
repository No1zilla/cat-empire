# 📌 TASK-056: Зачисление +5 гемов за рекламу на кнопке «⚡ Соединить» без авто-слияния

> **Статус:** ✅ ВЫПОЛНЕНО И ВЕРИФИЦИРОВАНО
> **Приоритет:** Высокий (P1 — UX бустеров)

---

## 🎯 Описание проблемы
Просмотр рекламы на кнопке «🎬 +5 💎» при недостатке гемов принудительно запускал авто-слияние сетки без выбора игрока.

---

## 🛠 Выполненные решения
1. В `AutoMergeButton.js` после завершения рекламы на баланс начисляются +5 💎, а кнопка переходит в режим `⚡ Соединить (5 💎)`.
2. Автоматический запуск слияния отменен.

---

## ✅ Критерии приёмки
- [x] За просмотр рекламы игрок получает 5 рубинов на баланс.
- [x] Игрок сам решает, когда нажать на кнопку слияния.
