# 📌 TASK-049: БАГ — Исправление кнопки «🐾 Меню» в HUD на Android-устройствах

> **Статус:** ✅ ВЫПОЛНЕНО И ВЕРИФИЦИРОВАНО
> **Приоритет:** Критический (P0 — пользовательский интерфейс)
> **Зависимости:** TASK-044 (HUD & Menu)

---

## 🎯 Описание баги

На тач-экранах Android смартфонов обработчик кнопки 🐾 в `HUD.js` зарегистрирован через устаревшее тач-событие `pointerdown` без обработки `pointertap`. В результате тач-жесты пальцем заглатываются или игнорируются родительскими контейнерами PixiJS.

---

## 🛠 Шаги исправления

1. **Добавить мульти-обработчик тач-событий в `HUD.js`**:
   Заменить `menuBtnContainer.on('pointerdown', ...)` на комбинацию:
   - `pointertap` (главный сенсорный клик в PixiJS v8)
   - `pointerdown` (с мгновенной анимацией нажатия)
   - `e.stopPropagation()` для предотвращения клика по нижней сетке
2. **Проверить `hitArea` кнопки 🐾**:
   Увеличить прозрачную область касания до `44x44px` (стандарт минимальной площади тапа Android).
3. **Проверить тач-отклик в `test_android_emulator.js`**.

---

## ✅ Критерии приёмки

- [ ] Тап по розовой кнопке 🐾 на Android гарантированно открывает Главное меню.
- [ ] Тач-клики по кнопке 🐾 не пробивают клик на ячейки сетки под ней.
