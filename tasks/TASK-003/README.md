## 🛠️ Описание возникших проблем и их решение

1. **Центрирование карточек котика в слотах 70×70**:
   - *Проблема*: Размер карточки котика `60×60` (CELL_SIZE - 10), при размещении в координаты слота `(x, y)` без сдвига карточка была прижата к верхнему левому углу ячейки.
   - *Решение*: В методе `getSlotPosition(slotIndex)` добавлены смещения `+5px` по X и Y, благодаря чему карточка идеальна сбалансирована внутри рамки.

2. **Анимация появления (Bounce)**:
   - *Проблема*: Нужна был плавная анимация появления котика без сторонних тяжелых библиотек.
   - *Решение*: Реализована легковесная анимация на `requestAnimationFrame` с масштабом `0 -> 1.2` за 150мс и `1.2 -> 1.0` за 100мс.
