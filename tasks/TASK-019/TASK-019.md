# 📌 TASK-019: Аудио-движок & Озвучка Котиков (SFX & Audio Engine)

> **Статус:** 🟡 В очереди
> **Приоритет:** Высокий
> **Зависимости:** TASK-015B

---

## 🎯 Цель

Добавить в игру аудио-составляющую (звуковые эффекты и фоновую музыку), повышая эмоциональную отдачу от скрещивания котиков и покупок.

---

## 🔊 Звуковые активы (SFX):

1. `meow.mp3` — Милое мяуканье при клике на кота на сетке.
2. `merge.mp3` — Сочный сокрушительный хруст + волшебный «дзинь» при скрещивании котиков.
3. `buy.mp3` — Звук звона монет при покупке нового котенка.
4. `level_up.mp3` — Торжественный фанфарный звук при открытии нового уровня кота.
5. `bgm_loop.mp3` — Расслабляющая фоновая Lo-Fi гитарная мелодия (с возможностью выключения в настройках).

---

## 🛠 Задачи для разработчика (`AudioService.js`):
- [ ] Создать класс `AudioService.js` на базе Web Audio API или HTML5 Audio.
- [ ] Добавить в верхний угол HUD кнопку 🔊 / 🔇 (Вкл/Выкл звук).
- [ ] Воспроизводить `meow.mp3` при клике/перетаскивании.
- [ ] Воспроизводить `merge.mp3` при скрещивании.

---

## ✅ Критерии приёмки
- Игра звучит живо и весело.
- Звук выключается по нажатию на иконку динамика в HUD.
- Настройки звука сохраняются в `localStorage`.
