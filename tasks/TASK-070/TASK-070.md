## 🎯 Цель
Создать простую HTML-страницу дашборда, доступную по защищённому URL (с базовой авторизацией), которая показывает ключевые метрики в реальном времени.

## 📊 Что показывает дашборд

### Блок 1: Активность (сегодня / 7 дней / 30 дней)
- DAU (Daily Active Users)
- Количество сессий
- Средняя длина сессии
- Новые пользователи сегодня

### Блок 2: Retention
- D1 Retention %
- D7 Retention %
- D30 Retention %

### Блок 3: Монетизация
- Всего показов рекламы сегодня
- Ad Fill Rate %
- Ad Completion Rate %
- Ads per DAU

### Блок 4: Геймплей-воронка
- Воронка: старт → покупка → слияние → реклама → авто-слияние
- Распределение максимальных уровней котиков (бар-чарт)

### Блок 5: Топ активных игроков (без персональных данных)
- Топ-10 по количеству сессий за 7 дней (анонимно)

## 🛠 Реализация

### Railway API: `GET /admin/dashboard`
- Защищён `Authorization: Bearer ADMIN_TOKEN` (из env Railway)
- Возвращает JSON со всеми метриками одним запросом
- Кэш: 60 секунд (чтобы не нагружать БД)

### Фронтенд дашборда
- Простая HTML-страница в `/admin/index.html`
- Vanilla JS + Chart.js для бар-чарта уровней
- Автообновление каждые 60 секунд
- Доступна по: `https://cat-empire-api.railway.app/admin`

## 🔐 Безопасность
- `ADMIN_TOKEN` — случайный 32-символьный токен в переменных окружения Railway
- Никаких персональных данных (только `user_id` хэш, без имени/фото)
- HTTPS обязателен (Railway даёт автоматически)

## ✅ Критерии приёмки
- [ ] `GET /admin/dashboard` возвращает все метрики за 1, 7, 30 дней
- [ ] HTML-дашборд доступен по защищённому URL
- [ ] Бар-чарт распределения уровней котиков отображается корректно
- [ ] Автообновление данных каждые 60 секунд работает
- [ ] Данные соответствуют SQL-запросам из TASK-068 и TASK-069
